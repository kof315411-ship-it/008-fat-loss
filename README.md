# 🥗 減脂餐智庫 (008-fat-loss)

> 收集各網站精選減脂餐，輸入手邊現有食材關鍵字，智慧匹配健康低卡、高蛋白減脂料理！

![專案預覽](https://images.unsplash.com/photo-1546069901-ba9599a7e63c?auto=format&fit=crop&w=1000&q=80)

---

## ✨ 核心特色

1. **🥑 冰箱食材智慧模糊配對**
   - 不需精準食材名稱，支援空白、逗號多詞輸入（例如：`雞肉 蛋 菇` 或 `番茄 豆腐`）。
   - 內建同義詞與延伸詞庫（如輸入「蛋」自動匹配水煮蛋、炒蛋、溏心蛋；輸入「牛」匹配牛里肌、牛排等）。
   - 顯示吻合比例標籤（如「100% 完美吻合」、「手邊有 2/3 種食材」），並高亮標註已有食材。

2. **🚫 避開／不吃食材過濾（忌口、過敏、挑食友善）**
   - 新增「🚫 避開不吃的食材」搜尋欄，自動完全過濾剔除含有該食材關鍵字的料理。
   - 支援大分類同義詞拓展（如輸入「海鮮」自動避開鮭魚、鯛魚、鱸魚、蝦仁、蛤蜊；輸入「辣」自動避開泡菜、辣椒、辣醬；輸入「牛」自動避開所有牛肉料理）。
   - 提供常見避開快捷鍵（🚫 避開海鮮、🚫 避開牛肉、🚫 避開辣味、🚫 避開香菜、🚫 避開起司/乳品、🚫 避開菇類）。

3. **📊 完整減脂料理資料庫**
   - 包含多道精選高蛋白、低碳減醣、低卡暖胃湯、超快即食料理。
   - 清楚標示 **熱量 (kcal)** 與三大營養素比例（**蛋白質、脂肪、碳水化合物**）。
   - 提供減脂烹飪小撇步（減油、去皮、控鈉與替代食材技巧）。
   - 附原食譜來源網站連結（愛料理 iCook、Cookpad、楊桃美食網等）。

4. **🛒 一鍵生成採買清單**
   - 在食譜詳情中可「一鍵將缺少的食材加入採買清單」。
   - 採買抽屜支援勾選完成進度，並可一鍵複製文字傳送至 LINE 或備忘錄。

5. **❤️ 收藏與自訂私房食譜**
   - 支援將喜歡的減脂料理加入「我的收藏」。
   - 支援新增個人自訂減脂食譜，所有資料安全保存在瀏覽器 LocalStorage 中。

## 🚀 快速開始

本專案為純前端 Single Page Application (SPA)，無任何後端依賴，即開即用！

### 本地執行
1. 直接在瀏覽器中雙擊開啟 `index.html`。
2. 或使用任何靜態網頁伺服器（例如 VS Code Live Server 或 Python）：
```bash
# Python 3
python -m http.server 8000
```
開啟瀏覽器訪問 `http://localhost:8000`

### 🌐 啟用 GitHub Pages 線上瀏覽
1. 進入 GitHub Repository 的 **Settings** -> **Pages**。
2. 在 **Branch** 選取 `main`，資料夾選取 `/ (root)`，點擊 **Save**。
3. 幾分鐘後即可透過 `https://kof315411-ship-it.github.io/008-fat-loss/` 線上使用！
